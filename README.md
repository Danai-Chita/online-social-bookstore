# Online Social Bookstore Web Application

Σχεδίαση και υλοποίηση μιας διαδικτυακής εφαρμογής «κοινωνικού βιβλιοπωλείου», η οποία επιτρέπει στους χρήστες να ανταλλάσσουν δωρεάν μεταχειρισμένα βιβλία.  
Οι χρήστες μπορούν να δημιουργούν λογαριασμό, να δημοσιεύουν προσφορές βιβλίων, να αναζητούν διαθέσιμα βιβλία και να λαμβάνουν προτάσεις βάσει των προτιμήσεών τους.

> Ακαδημαϊκό έργο που αναπτύχθηκε στο πλαίσιο μαθήματος, με χρήση Scrum και ομαδικής ανάπτυξης.

---

## Εισαγωγή (Intro)

Η εφαρμογή στοχεύει στη δημιουργία μιας απλής και φιλικής πλατφόρμας ανταλλαγής βιβλίων μεταξύ χρηστών.  
Κάθε χρήστης μπορεί:
- να προσφέρει βιβλία που δεν χρειάζεται,
- να αναζητήσει βιβλία άλλων χρηστών,
- και να επικοινωνήσει μαζί τους για την ολοκλήρωση της ανταλλαγής.

Η ανάπτυξη βασίστηκε σε αρχές αντικειμενοστραφούς σχεδίασης και αρχιτεκτονική MVC.

---

## Πώς λειτουργεί (How it works)

- Οι χρήστες εγγράφονται και συνδέονται στο σύστημα.
- Κατά την πρώτη σύνδεση συμπληρώνουν το προφίλ τους και τις προτιμήσεις τους (π.χ. αγαπημένες κατηγορίες ή συγγραφείς).
- Οι χρήστες μπορούν να:
  - προσθέσουν νέες προσφορές βιβλίων,
  - αναζητήσουν βιβλία με βάση τίτλο ή συγγραφέα,
  - υποβάλουν αιτήματα για βιβλία άλλων χρηστών.
- Το σύστημα υποστηρίζει:
  - **ακριβή** και **προσεγγιστική αναζήτηση**,
  - προτάσεις βιβλίων βάσει κατηγοριών, συγγραφέων ή συνδυαστικά.
- Οι ιδιοκτήτες των βιβλίων μπορούν να δουν ποιοι χρήστες έχουν υποβάλει αίτημα και να προχωρήσουν στην ανταλλαγή.

Η εφαρμογή υλοποιεί διαχωρισμό ρόλων μέσω:
- Controllers (διαχείριση αιτημάτων χρήστη),
- Services (επιχειρησιακή λογική),
- Domain Models και Mappers (δεδομένα & βάση).

---

## Χαρακτηριστικά (Features)

- Εγγραφή και σύνδεση χρηστών
- Διαχείριση προφίλ χρήστη
- Προσθήκη και διαγραφή προσφορών βιβλίων
- Αναζήτηση βιβλίων με φίλτρα
- Σύστημα αιτημάτων βιβλίων
- Προτάσεις βιβλίων βάσει προτιμήσεων
- Υλοποίηση στρατηγικών αναζήτησης και προτάσεων (Strategy Pattern)

---

## Τεχνολογίες (Technologies)

- Java
- Spring Framework (MVC)
- MySQL
- UML διαγράμματα (Use Case, Domain Model, Services, Controllers)
- Scrum / Sprint-based ανάπτυξη

---

## Πώς χρησιμοποιείται (How to use)

1. Εκκίνηση της εφαρμογής
2. Εγγραφή ή σύνδεση χρήστη
3. Συμπλήρωση προφίλ και προτιμήσεων
4. Προσθήκη προσφοράς βιβλίου
5. Αναζήτηση διαθέσιμων βιβλίων
6. Υποβολή αιτήματος για βιβλίο
7. Επικοινωνία με τον ιδιοκτήτη του βιβλίου για την ανταλλαγή
